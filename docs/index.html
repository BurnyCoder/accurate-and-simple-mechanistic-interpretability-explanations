Accurate and simple SAE feature explanations

Detection scoring (Paulo et al. 2024, via delphi) gives each explanation an above-chance accuracy J = 2·BA − 1. This project multiplies it by a length factor: S = max(J, 0) · 2−L/H, where L is the length in tokens. Move the half-life H to see how the ranking of explanations changes. The data is GPT-2 small, SAE 6-res-jb, with explanations from Neuronpedia and Llama-3.1-70B, scored by Llama-3.1-70B. Code, paper and pre-registration.
